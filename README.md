# 麒麟斗地主 · 单机版

一个完整、离线、零运行时依赖的三人斗地主小游戏：麒麟与电脑玩家“掘开”“旭旭宝宝”使用标准 54 张扑克牌对局，并带有持久化麒麟币、可选记牌器、回合倒计时和特殊牌型动画。没有账号、联网匹配、充值、真钱积分、广告或跟踪代码。

![麒麟斗地主游戏截图](docs/game-screenshot.png)

截图文件位于 `docs/game-screenshot.png`；游戏运行不依赖该截图或任何外部图片。

## 当前状态

项目已经可以完整运行。已完成自动化规则/流程/AI 测试和 Microsoft Edge 真实浏览器完整对局验收；游戏可直接从本地文件打开，不需要安装依赖或启动服务器。

## 功能

- 1 名真人玩家 + 2 名带蒙特卡洛搜索的 AI 玩家。
- 三位玩家分别使用根目录的 `麒麟.jpg`、`掘开.jpg`、`旭旭宝宝.jpg` 作为头像；三人按麒麟 → 旭旭宝宝 → 掘开的逆时针方向行动。
- 标准 54 张牌、每人 17 张、3 张底牌，地主拿底牌后 20 张。
- 完整叫分：中央 10 秒倒计时，不叫、1 分、2 分、3 分；3 分立即定地主；全不叫自动重发。
- 地主确定后进入 5 秒倍率选择，三人可选不加倍（×1）、加倍（×2）或超级加倍（×3）；头像旁直接显示“不加倍／加倍／超级加倍”，全部选定后展示 3 秒再正式出牌。
- 地主先出、同型同长度跟牌、炸弹/王炸、两家连续不出后重置出牌权。
- 点击选牌或按住立即滑动多选、提示、不出；手牌固定按牌力排列。连续选择 3 个顺子点数后会自动补全：领牌补到手中最大连续段，跟牌只补到上家相同长度。
- “提示”会按合理程度逐个轮换全部合法候选，全部看完后再次点击会清空选牌；三带一、三带二默认使用最小附件，并尽量保留王、2、A 等控制牌。
- 每位玩家有独立出牌区，所出牌保留到本人下一回合；两位电脑的真实剩余牌背水平排列在头像框正下方，与出牌区互不重叠。
- 出牌阶段有醒目的 20 秒倒计时和逆时针收缩时间环；电脑按固定概率选择 0～6 秒思考时间，其中立即出牌约占 10%。
- 游戏顶部可随时开启“电脑托管”，由同难度 AI 代替麒麟完成叫分、倍率选择和出牌；托管期间牌桌变暗并显示醒目标识。
- 三人初始各有 10000 麒麟币，底注 100；叫分、个人加倍、炸弹/王炸、春天与反春天参与倍率，结算余额通过浏览器本地存储延续到下一局。
- 可选经典记牌器，显示两位对手尚未打出的各点数牌张数。
- 简单、普通、困难三档 AI；共同使用同一套合法动作生成器。简单档走纯启发式（最快），普通/困难档在固定时间预算内追加真实 rollout 蒙特卡洛精修，目标上限分别为 10000/20000 次（实际次数受时间预算限制）；进入残局后改用完全信息精确求解。
- 主菜单、规则、设置、重开、返回菜单、胜负结算。
- CSS 发牌/选牌/炸弹投掷/火箭发射/飞机起飞/结果动画，并尊重 `prefers-reduced-motion`。
- 使用本地 MP3 播放背景音乐、发牌、出牌和点牌音效，并用 Web Audio API 加强特殊牌型反馈；音乐和音效默认开启，各自可在 0～30 倍之间独立调节。
- 适配常见桌面、移动横屏和窄竖屏；支持键盘焦点、方向键浏览手牌和 `aria-live` 状态提示。
- 所有素材均随项目保存在本地，无远程脚本、字体、图片或音频请求。

## 最简单的启动方法

1. 打开项目文件夹。
2. 双击根目录的 `index.html`。
3. 在主菜单选择难度，点击“开始新对局”。

游戏使用经典脚本而非 ES Modules，因此 `file://` 本地打开即可运行。若浏览器或安全软件禁止本地脚本，可使用任意静态服务器打开此目录，但正常情况下不需要。

## 游戏操作

- 叫地主时，只能选择高于当前最高分的分数，或选择“不叫”。
- 轮到你出牌时，点击手牌使其抬起；再次点击可取消。
- 也可以按住一张手牌后不松开并横向滑动，按下时会立即进入连续选择，无需等待长按判定。
- “提示”会选择一组合法牌；若没有可压的牌，会提示选择“不出”。
- “出牌”会验证牌型和大小；非法操作不会改变手牌或轮次，并显示中文原因。
- 新一轮拥有出牌权时不能“不出”。
- 对局中可重新开始或返回主菜单；这两项会先确认，避免误操作。
- 跟牌倒计时结束会自动“不出”；自由出牌不能不出，因此超时会自动打出一手合法牌。
- 任一玩家麒麟币不大于 0 后不能继续开局，可在设置中使用“重置三位玩家的麒麟币”。

## 麒麟币结算

麒麟币仅为本设备上的虚拟游戏积分，不是真钱，也没有支付或充值入口。每局单份结算为：

```text
100 × 最高叫分（1/2/3）× 2^炸弹及王炸次数 × 春天倍率（1或2）
```

结算时，地主与每位农民之间的一份输赢还要再乘地主倍率和该农民倍率。地主胜利时从每位农民各赢对应的一份，农民胜利时方向相反。地主获胜且农民没有成功出过牌为“春天”；农民获胜且地主只成功出过一手牌为“反春天”。每次结算总麒麟币守恒。

## AI 策略

AI 不随机拼牌，也没有引入机器学习模型。其流程为：

```text
手牌与桌面状态 → 枚举合法候选 → 过滤能压过的牌 → 统一启发式评分
                 ├─ 残局（剩余总牌数 ≤ 8）→ 完全信息精确求解（团队 negamax + 记忆化）
                 └─ 中盘（普通/困难）→ 时间预算内的真实 rollout 蒙特卡洛精修
```

评分会考虑剩余牌数、牌型完整性、是否拆炸弹/王炸、最小代价跟牌、一次出完、地主威胁、对手一手出完风险和农民队友协作。三档难度共用同一套规则引擎与评分：

- **简单**：纯启发式，响应最快，适合熟悉规则。
- **普通**：启发式 + 短时间预算（约 30ms）内的真实 rollout 蒙特卡洛精修。
- **困难**：启发式 + 更长时间预算（约 55ms）内的真实 rollout 蒙特卡洛精修。

进入残局后，AI 改用完全信息精确求解（把「地主 vs 两位农民」建模为两阵营零和博弈，用团队 negamax + α-β 风格的记忆化在剩余总牌数不超过 8 张时算出精确胜负），残局关键决策（是否压炸弹/王炸、是否让牌）从「估」变为「算」。

叫地主同样依据手牌质量：王、2、A、炸弹、三张和连续结构会影响评分，不是纯随机决定。

## 自动化测试

玩游戏不需要 Node.js。只有运行开发测试时才需要 Node.js 18 或更高版本。

```bash
npm test
```

也可不经过 npm，直接运行：

```bash
node --test tests/rules.test.js tests/comparator.test.js tests/ai.test.js tests/game-flow.test.js tests/economy.test.js tests/card-counter.test.js
```

当前 `npm test` 覆盖 95 项（另有 `tests/controller-behavior.test.js` 的 2 项控制器行为测试），包括：

- 14 种牌型的正确、错误、边界和排列不敏感用例；
- 同型比较、不同长度、炸弹和王炸；
- 发牌唯一性、叫分、全不叫重发、地主底牌、两次不出重置；
- 非当前玩家、重复牌、手牌外牌、非法牌型和压不过时状态完全不变；
- AI 候选合法性、飞机带单翅膀组合的完整枚举、智能提示轮换、三带一/三带二最小附件、最小合法跟牌、炸弹保护、队友让牌、重新获得牌权后的低牌清理、提示与决策统一评分、完全信息残局精确求解、真实 rollout 蒙特卡洛次数和完整自动对局。
- 逆时针座次、倍率选择、地主揭晓阶段、个人出牌区清理时机、麒麟币守恒/倍率/破产阻断和记牌器计数。

真实浏览器验收还完成了 1440×900 桌面完整对局，以及 844×390、667×375、390×844 三种响应式视口检查；控制台错误、页面异常和外部网络请求均为 0。

## 已知限制

- AI 是增强后的可解释启发式玩家，会保护王炸、长牌型和残局结构，但不等同于竞技级 DouZero 模型。
- 麒麟币保存在当前浏览器的 `localStorage`；清除网站数据、换浏览器或换设备不会自动同步余额。
- 本版本没有在线匹配、账号系统、跨设备存档、充值或真钱功能。
- 飞机翅膀在不同地区/平台存在变体；本项目采用文档所述严格口径。
- 音频必须在首次用户交互后才能启动；这是现代浏览器的自动播放限制，关闭音频不影响游戏。
- 浏览器完整自动化验收在 Microsoft Edge/Chromium 完成；其他现代桌面浏览器基于标准 Web API 设计，但未在本次环境逐一做完整自动对局。
