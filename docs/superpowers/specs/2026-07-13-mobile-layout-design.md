# 手机端防重叠布局设计

## 目标

解决窄屏竖屏和低高度横屏中，玩家座位、剩余牌、底牌、记牌器、出牌区、倒计时、操作栏、手牌与电脑托管提示相互覆盖的问题，同时保留桌面端现有布局。

## 设计

- 桌面端继续使用现有坐标和尺寸。
- 高度不超过 520px 的横屏使用紧凑分区：两名电脑位于上方两角，真人与真人出牌区位于下方两角，操作栏居中并与底部手牌保留安全间距。
- 宽度不超过 780px 的竖屏使用纵向空间带：两名电脑、剩余牌、底牌、记牌器、电脑出牌区、桌面中心、真人信息/出牌区、操作栏、手牌依次排列。
- 竖屏 HUD 使用两行结构，第一行放功能按钮，第二行放局面状态，避免横向挤压。
- 记牌器在手机端单行横向滚动，不再换行增高；托管提示缩为中央胶囊，只保留核心文字。
- 使用 `safe-area`、`dvh` 和最小 44px 触控目标兼容刘海屏与手机浏览器工具栏。

## 验收

浏览器回归测试覆盖 844×390、667×375、390×844，检查页面无横向滚动、操作和手牌可见、关键区域没有矩形重叠、按钮触控尺寸不小于 44px，并检查托管提示不会覆盖玩家、底牌或记牌器。
